ABZAL UTESHOV — ASTANA — LUXURY INVITATION
============================================

Ашу үшін index.html файлын браузерде ашыңыз (немесе кез келген статикалық
хостингке жүктеңіз — GitHub Pages, Netlify, Vercel т.б.).

ҚҰРЫЛЫМ
-------
index.html            — беттің құрылымы
style.css             — барлық стильдер (алтын/қара люкс тақырып)
script.js             — countdown, билет модалы, lightbox, музыка, confetti
assets/images/         — сурет орындары (artist.jpg, gallery-*.jpg)
assets/music/          — instrumental.mp3 (фондық музыка)
assets/tickets/        — қолданушылар жүктеген билет суреттері (тек көрсету үшін, сервер жоқ)

МАҢЫЗДЫ ЕСКЕРТУ — суреттер
---------------------------
Нақты адамның (Абзал Үтешовтың) авторлық құқығы қорғалған фотосуретін
дайын түрде осы жобаға автоматты түрде қоса алмаймын. Орнына:
  - assets/images/artist-placeholder.svg — алтын жиекті силуэт-орынбасар,
    суретте нақты фото жоқ болса, беттегі барлық орынға автоматты шығады.
  - Нақты фотоны қосу үшін: өзіңіздің (немесе рұқсаты бар) суретті
    assets/images/artist.jpg деп сақтаңыз — сайт оны автоматты түрде
    қолданады (портрет, билет суреті).
  - Галерея бөлімі қазір градиентті "орын толтырғыштармен" көрсетілген
    (.gallery-item ...). Нақты фотолар қосу үшін style.css ішіндегі
    .gi-1 … .gi-6 background-ты url('assets/images/gallery-1.jpg') т.б.
    етіп ауыстырыңыз.

МУЗЫКА
------
assets/music/instrumental.mp3 файлын өзіңіз қосыңыз (авторлық құқығы
таза/лицензияланған трек). Файл болмаса, музыка түймесі басылғанда
ештеңе ойналмайды (қате шықпайды).
